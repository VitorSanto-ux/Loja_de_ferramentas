O projeto é um sistema de cadastro de usuários feito em PHP e MySQL, que permite cadastrar, listar, editar e excluir usuários. Para organizar melhor o código, foi utilizado o padrão MVC, que separa o sistema em três partes: Model, que cuida do banco de dados; View, que mostra as páginas e formulários; e Controller, que faz a ligação entre as duas partes.

Para desenvolver o projeto, foram utilizadas ferramentas como PHP, MySQL, HTML e XAMPP. O sistema utiliza o PDO para conectar ao banco de dados e realizar as operações necessárias.

O objetivo do projeto é colocar em prática os conhecimentos de programação, aprender a trabalhar com banco de dados e entender melhor como funciona a organização de um sistema usando o padrão MVC.
